# ShootTracker

O ShootTracker cria ferramentas para treino, acompanhamento e evolução no tiro esportivo.

## O que fazemos

- Desenvolvemos o aplicativo ShootTracker para registrar e acompanhar treinos.
- Mantemos automações de build, testes e distribuição para iOS e Android.
- Publicamos documentação para orientar o desenvolvimento e a operação dos projetos.
